\begin{abstract}
Variable importance, typically impurity-based (mean decrease in impurity) is 
the default way to read which features matter in a random forest regression, and it
is routinely misread as an effect size comparable to a linear-model coefficient.
This we demonstrate through LLM-assisted screen of the literature, which 
%  citing the \code{ranger} R package
suggests that about one in six papers that interpret an impurity importance ranking rely on
it without such corroboration, including heavily-cited work. 
What impurity importance actually estimates is each feature's contribution to the variance of the
response. We make the practical consequences of this concrete through a sequence of
controlled experiments: importance (i) grows with the \emph{square} of a linear
coefficient; (ii) assigns an interaction's variance to the
interacting variables, so a feature with no effect of its own can top the
ranking; and (iii) gives \emph{identical} scores to a genuinely
non-linear effect and to a linear effect on a skewed feature. These biases are
distinct from the long-known bias towards features with many distinct values,
and the usual corrections do not help: bias-corrected impurity, permutation
importance, and SHAP-based importance scores all inherit them. No importance
measure that reduces a feature to a single number
can separate the \emph{shape} of its effect from the \emph{spread} of its
values.

\end{abstract}

\section{Controlled experiments}
The experiments that follow use synthetic data with known ground truth to isolate, one mechanism at a time, what impurity importance measures when it is read as an effect size. In each case the data-generating process is fully specified, the features are independent except where dependence is the point, and the impurity ranking is set beside the ordinary-least-squares coefficient on the same data --- the per-unit effect a reader is tempted to see in it. The unifying finding is that importance tracks each term's contribution to the variance of the response, $\mathrm{Var}(f_j(X_j))$, not its per-unit slope: it grows with the \emph{square} of a linear coefficient (Section~\ref{sec:linear}), credits an interaction's variance to the interacting variables even when neither has a marginal effect (Section~\ref{sec:interactions}), and therefore prices a non-linear effect at the variance it contributes (Sections~\ref{sec:variance}--\ref{sec:nonlinear}), leaving effect shape and feature spread exactly indistinguishable to any marginal importance measure (Section~\ref{sec:confound}).

\section{Data and code availability}
\label{sec:availability}

All code and data supporting this paper are supplied as supplementary
material, in a single archive: the R scripts that generate the
controlled experiments and figures of
Sections~\ref{sec:linear}--\ref{sec:confound} (with a one-line command to
reproduce every number cited there), the corpus-construction and
full-text-retrieval pipeline, the relevance filter, the verbatim screening and
adjudication prompts, and the per-paper structured records and verdicts behind
Section~\ref{sec:prevalence-results}, with a one-line tally that reproduces
every count in it. The corpus manifest records every work screened, with its
identifier and retrieval timestamp; the retrieved full texts themselves are not
redistributed, and the included retrieval script regenerates them from Europe
PMC.
